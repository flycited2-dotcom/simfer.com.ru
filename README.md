# simfer.com.ru

Статический сайт ООО «ТЕХНОЛАЙН ТРЕЙД».

## Файлы

- `index.html` — копия опубликованной страницы https://simfer.com.ru/, полученная 7 ноября 2026 года. HTML, CSS и JavaScript находятся в одном файле.
- `logo.png` и `photo_2024-10-22_18-58-20.jpg` — изображения с действующего сайта.
- `archive/` — четыре исходных файла из локальной папки Downloads, сохранённые без изменений: index.html (15.12.2025), index(1).html и index(2).html (16.12.2025), index(3).html (09.01.2026).

## Просмотр и размещение

Откройте `index.html` в браузере. Для размещения загрузите index.html и оба изображения в корень сайта. Папку archive публиковать не требуется.

Шрифты Google Fonts, карта Яндекса и Яндекс Метрика используют внешние сервисы. Их подключения сохранены как на опубликованном сайте.

Это восстановленный комплект статического сайта. Серверные настройки и история разработки до этого восстановления в репозиторий не входят.
