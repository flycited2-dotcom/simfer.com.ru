# simfer.com.ru — ТЕХНОЛАЙН ТРЕЙД

Исходный код сайта: https://github.com/flycited2-dotcom/simfer.com.ru.

Статические главная и пять страниц направлений; общие стили и клиентский код в assets/. Форма работает через request.php (PHP 8.1+). Метрика сохранена. Исходные HTML-версии за декабрь 2025 — январь 2026 находятся в archive/ и не предназначены для выкладки.

## Разработка

```sh
npm ci
npm run build
php tools/update-sitemap.php
npm run check
npm run release
```

Node.js нужен только для инструментов разработки. Содержимое content/ используется сборкой: site.json — реквизиты, directions.json — тексты пяти направлений. Главная редактируется в index.html; общий код шапки SEO и формы — scripts/site.mjs.

Для просмотра формы запускайте PHP-сервер, а не file://:

```sh
php -d disable_functions=mail -S 127.0.0.1:8095 -t .
```

Эта локальная команда намеренно отключает отправку писем.

## Выкладка

Загружать **весь пакет релиза**, включая .htaccess, assets/, PHP и пять каталогов направлений. Только index.html и двух картинок больше недостаточно. Полный порядок, настройка cron, WWW/HTTPS и live-проверки: [docs/DEPLOY.md](docs/DEPLOY.md).

Папкой /articles/ управляет отдельный робот Claude. Ни сборка, ни релиз её не изменяют. Загрузка должна быть аддитивной, без --delete. После автовыкладки запускать на хостинге tools/update-sitemap.php, дополнительно настроить cron каждые пять минут. В релизе нет локальной папки статей; sitemap после загрузки пересоздаётся по реальному document root.
