## Decisions
- Сохраняем существующее оформление, Title/H1 главной и Метрику; превращаем существующие заголовки div в H2.
- 4 товарных направления + отдельная страница для госзаказчиков; статьи не генерируем и не удаляем.
- Форма принимает текст спецификации/ссылку, email и организацию, без загрузки файлов на сервер. PHP mail(), ошибки видимы, без обещания доставки в ящик.

- Успех: все публичные индексируемые страницы имеют уникальные canonical/OG/H1, sitemap валиден, все новые страницы/ресурсы доступны, PHP validation/CSRF/mail-failure проверены, articles сохранён при deploy.

- Риск: нет доступа Sprinthost — готовим полный проверенный пакет независимо, для выкладки нужен доступ.
